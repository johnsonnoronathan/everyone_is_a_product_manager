# Scope (round 2: re-review after fixes)

- **Engagement:** Phase 6 re-verification of the 23 round-1 findings (`demo/flash-sale/sample-reports/fixed-round1/launch-review/`, commit `d572634`, verdict NO-GO), plus a fresh four-lens review of the changed code. Report-only: no app code was changed.
- **Product:** a one-page flash sale for 100 pairs of limited-edition sneakers ("Limited Edition Holiday Sneakers", $49.99), one pair per customer. The sale opens at midnight with an email blast.
- **Users / scale:** public consumers. About 3,000 visitors within 60 seconds of opening (owner's figure); performance target planned at 3× peak factor (`demo/flash-sale/peak-brief.json`).
- **Sensitive data:** customer email addresses and shipping addresses (`orders.ship_to`, now required). Reviewer first names (public). No passwords; no card data in the app.
- **Money flows:** the app server calls the payment provider's charge API itself (`POST {PAYMENT_URL}/charge`, secret key, one random idempotency key per order, 3 s timeout), then settles unknown outcomes with a background reconciler. Not a hosted checkout: amount, idempotency, timeout handling and reconciliation are this code's responsibility. No refunds, coupons or webhooks in the code.
- **Auth & roles:** shopper (signed session token `payload.HMAC-SHA256`; in production issued by a managed magic-link identity provider; `POST /api/login` is a test-only stub behind `DEMO_LOGIN=1`, refused in production). Admin: one shared static `X-Admin-Token` for `POST /api/admin/sale` and `GET /api/admin/stats`; the reset route exists only with `ENABLE_TEST_ROUTES=1` (refused in production).
- **Stack & hosting:** Node.js 22, no third-party npm dependencies. One Node.js process behind a load balancer today; a second instance may come later in the season. Hosted Postgres in production; simulated by `demo/flash-sale/shared/db.mjs` (10-connection pool, ~3 ms per query, in-memory SQLite, persistent with `DB_FILE`). Payment provider simulated by `demo/flash-sale/shared/fake-payment-provider.mjs` (Stripe-like: idempotency keys, 409 while a key is in flight, completes charges after the caller hangs up, 2% of calls hang 30 s).
- **Code under review:** `demo/flash-sale/fixed/server.mjs` (657 lines), the browser front end `demo/flash-sale/shared/public/` (`index.html`, `app.js`, `style.css`), and the team's new `demo/flash-sale/fixed/RUNBOOK.md`. Simulated infrastructure is reviewed only for how the app uses it. `demo/flash-sale/run.mjs` is the demo launcher (demo secrets, `DEMO_LOGIN=1`, `ENABLE_TEST_ROUTES=1`, `SEED_DEMO_DATA=1` by default).
- **Environments:** local only. **Live checks allowed against:** instances started by the reviewer on ports 3100/4200 (`PORT=3100 PAYMENT_PORT=4200 node demo/flash-sale/run.mjs fixed`, with simulator knobs), nothing else.
- **Launch:** midnight opening (date not given; the runbook's example is `2026-11-27T00:00:00-05:00`, 41 days after this review), expected peak 3,000 visitors in 60 s.
- **Regulations to keep in mind (flagged, not certified):** GDPR / UK GDPR, CCPA/CPRA (emails and shipping addresses are personal data); PCI DSS scope depends on the production card integration (still not in the code); consumer-protection rules on advertised limited stock and start times.
- **Out of scope:** the simulations themselves; `demo/flash-sale/naive/`; the acceptance suite source (`demo/flash-sale/acceptance/`; only its round-2 report is read, after the findings were written); the production identity-provider and card integrations (not in the repo); cloud/LB configuration.
- **Operations:** backups, error tracking, alerting and on-call were **not confirmed** by the team (no interview). Treated as unverified.
- **Risk tier: 3 (High)**, unchanged from round 1: the app calls the card provider's charge API itself, so charge amounts, idempotency, timeouts and reconciliation are this code's responsibility, and the whole sale happens in a promoted 60-second spike. Tier 3: any open High blocks, operational readiness is mandatory, and an independent penetration test is recommended.
